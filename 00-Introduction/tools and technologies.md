## 7. Linux Networking Commands

The following commands are useful for basic network configuration and troubleshooting in Kali Linux.

| Command | Purpose |
|---|---|
| `ip addr` | Displays network interfaces and IP addresses |
| `ip route` | Displays routing information |
| `nmcli` | Manages and displays NetworkManager connections |
| `ping` | Tests network connectivity |
| `nslookup` | Checks DNS resolution |
