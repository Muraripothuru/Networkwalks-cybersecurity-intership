# Cybersecurity Internship – Learning Objectives

## 1. Introduction

The objective of this internship is to develop foundational and practical cybersecurity skills through technical learning, laboratory exercises, and authorized security activities.

## 2. Technical Learning Objectives

### 2.1 Linux Fundamentals
- Understand the Kali Linux operating system.
- Learn basic Linux terminal commands.
- Understand file and directory management.
- Learn user and permission management.

### 2.2 Networking Fundamentals
- Understand IP addresses and subnet masks.
- Learn about gateways and DNS.
- Understand TCP and UDP protocols.
- Configure and troubleshoot network connections.
- Understand NAT networking and virtual networks.

### 2.3 Virtualization
- Understand virtualization concepts.
- Configure virtual machines using Oracle VM VirtualBox.
- Set up isolated laboratory environments.
- Configure virtual network adapters.
- Create and manage virtual machine snapshots.

### 2.4 Cybersecurity Fundamentals
- Understand common cybersecurity threats.
- Learn about vulnerabilities and security risks.
- Understand network security concepts.
- Explore security assessment methodologies.
- Understand ethical hacking principles.

### 2.5 Security Tools
- Learn how to use cybersecurity tools.
- Understand network scanning and analysis.
- Explore packet analysis.
- Practise interpreting tool outputs.
- Document findings from authorized lab exercises.

## 3. Practical Learning Objectives

- Complete assigned weekly cybersecurity tasks.
- Configure and maintain a virtual lab environment.
- Perform practical exercises in authorized environments.
- Troubleshoot technical problems.
- Maintain organized technical documentation.
- Record screenshots and evidence of completed tasks.

## 4. Professional Development Objectives

- Improve technical problem-solving skills.
- Develop research and independent learning abilities.
- Improve technical writing and documentation.
- Practise responsible handling of information.
- Develop communication and reporting skills.

## 5. Expected Learning Outcomes

By the end of the internship, I aim to:

- Understand fundamental cybersecurity concepts.
- Work comfortably with Kali Linux.
- Understand basic computer networking.
- Configure and manage virtual machines.
- Use selected cybersecurity tools in authorized environments.
- Document technical activities and findings.
- Demonstrate practical knowledge through completed tasks and projects.

## 6. Conclusion

These learning objectives will guide my progress throughout the internship. They may be updated as new topics, assignments, and practical activities are introduced.
