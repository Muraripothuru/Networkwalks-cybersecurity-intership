# Week 03 – Technical Findings

## 1. John the Ripper

John the Ripper is a password security auditing tool used to identify weak passwords by testing password candidates against stored password hashes.

### Findings

- Learned how to extract PDF password hashes.
- Understood the structure of PDF password hashes.
- Learned how to use wordlists for password auditing.
- Practised using John the Ripper through Kali Linux.

## 2. Networkwalks Tools

The Networkwalks Hash Calculator and Password Cracker provide a browser-based workflow for extracting and auditing password hashes.

### Findings

- Learned how to extract hashes from protected PDF files.
- Understood the process of submitting hashes to a password auditing tool.
- Explored browser-based password recovery.

## 3. Security Recommendations

- Use long and unique passwords.
- Avoid commonly used passwords.
- Use a password manager.
- Enable multi-factor authentication wherever available.
- Never reuse passwords across important accounts.
- Regularly review password security.

## 4. Overall Learning Outcome

The Week 03 exercises demonstrated how weak passwords can be vulnerable to dictionary-based attacks and reinforced the importance of strong password practices.
