
# Week 02 – Cybersecurity Internship Activities

## Overview

This folder documents the practical activities completed during Week 02 of my Networkwalks Cybersecurity Internship.

The activities covered:

- PM1 – Footprinting and Reconnaissance
- PM5 – Network Scanning using Nmap and Zenmap

## Activities

| Activity | Description | Status |
|---|---|---|
| PM1 | Domain footprinting and reconnaissance using Kali Linux tools | Completed |

- cURL

- DNSRecon

Target: `networkwalks.com`

## PM5 – Network Scanning

Tools and environment:

- Kali Linux
- Nmap
- Zenmap
- Oracle VirtualBox
- Isolated Host-only Network

Test target: Windows host-only adapter (`192.168.56.1`)

See: [PM5 Documentation](./PM5-Zenmap-Network-Scanning/README.md)

## Learning Outcomes

- Practised domain and DNS information gathering.
- Identified publicly visible web technology indicators.
- Inspected HTTP response headers.
- Learned how to identify a reported Web Application Firewall.
- Configured an isolated virtual network.
- Practised Nmap host discovery.
- Learned the importance of authorised and controlled security testing.
